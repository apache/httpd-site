The "users-de" mailing list was a place for German-speaking users of the Apache HTTP Server. It was created in 2002, but closed and archived in 2026, due to lack of traffic.

**Please use the main English-language users mailing list:** 
>    Please use the main [users mailing list](userslist.html) of the Apache HTTP Server if you are looking for support.

**Archive of the users-de mailing list:**
> Archives are available at the [ASF Mailing list archives](https://lists.apache.org/list.html?users-de@httpd.apache.org).
